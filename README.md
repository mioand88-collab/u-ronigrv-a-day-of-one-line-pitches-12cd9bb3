# A Day of One-Line Pitches

One sentence that talks a friend who has never coded into letting an AI agent build their first app idea on make.fun — plain words, a concrete reason to say yes now, and nothing overpromised.

## Run it

```sh
node main.ts
```

It writes the sentence to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
